# Bauplan App

Werkstatt-Planer im Browser: SAMLA-Kistenregal, French-Cleat-Wand, Führungsschienen & Schablonen.
Pläne und 1:1-Schablonen zum Ausdrucken. Einfach `index.html` öffnen.

## Fertige Baupläne (PDF)

- [Nutlade für die Kante / Ecke – Bosch POF 500 A](plaene/Nutlade-Kante-Ecke-POF500A.pdf)
- [Nutlade für die Fläche (mittig) – Bosch POF 500 A](plaene/Nutlade-Flaeche-POF500A.pdf)
- [Klapp-Werkbank (Parallelogramm): Regal mit 4 Ebenen ↔ Werkbank 2,20 m – Turm 2,28 m inkl. Kiste, für 2,34 m Deckenhöhe](plaene/Klapp-Werkbank-Parallelogramm.pdf)

Hinweis: Die beiden Nutladen-Pläne warnen, solange kein Fräser mit Freigabe für 27.000/min eingetragen ist.
